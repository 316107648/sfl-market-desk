# Sunflower Market Pro v29

## Curral visual + registro de mimo
- Galinhas continuam no galinheiro visual.
- Animais do Barn agora aparecem em um curral visual no mesmo conceito.
- Cada animal permite registrar manualmente um dos tres resultados de mimo.
- Os valores dos tres mimos sao editaveis enquanto a API nao entregar essa regra com confiabilidade.
- O painel mostra o total/restante para o proximo nivel.
- O progresso de mimo e salvo localmente e sincronizado com a nuvem por Farm ID.
- O diagnostico bruto da API e a analise economica ficaram recolhidos por padrao.
