# Sunflower Market Pro v27 — Diagnóstico completo da API dos animais

Esta versão adiciona um painel expansível em cada animal da Casa dos Animais para descobrir exatamente quais dados a Community Farm API está entregando.

O diagnóstico procura inclusive em objetos aninhados por campos relacionados a nível, XP, sono/acordar, produção (Egg/Feather/Wool/Milk), alimentação, comida favorita, buffs/boosts, affection/love/pet e próxima ação/request.

Também inclui **Ver JSON bruto deste animal**, permitindo comparar diretamente os dados da API com a janela exibida dentro do Sunflower Land. A Farm API Key não é incluída nesse JSON.

Objetivo: descobrir quais informações podem ser automatizadas antes de criar regras manuais para alimentação, mimos e rentabilidade.
