# Sunflower Market Pro v23 — Ferramentas completas de coleta/mineração

Atualização da calculadora compacta de break-even.

Incluído:
- Axe → Wood — 16 Coins
- Pickaxe → Stone — 3 Wood + 16 Coins
- Stone Pickaxe → Iron — 3 Wood + 5 Stone + 16 Coins
- Iron Pickaxe → Gold — 3 Wood + 5 Iron + 64 Coins
- Gold Pickaxe → Crimstone — 3 Wood + 3 Gold + 80 Coins

Os custos foram alinhados ao painel atual do jogo fornecido pelo usuário e a uma discussão do repositório Sunflower Land de julho/2026 (#7400).

Ferramentas de água, petróleo/areia e ferramentas de animais não foram preenchidas com receitas inventadas. A estrutura está pronta para adicioná-las assim que os custos atuais forem confirmados pela API/dados do jogo ou por prints do painel.
